# EduPilot — Python dependencies
#
# pyproject.toml is the source of truth for the dependency list. This file
# exists so `pip install -r requirements.txt` still works: it installs the
# project itself, which pulls in everything under [project.dependencies].
#
#   pip install -r requirements.txt     runtime only
#   pip install -e ".[dev]"             runtime + pytest/ruff
#
# Optional system dependency: Tesseract OCR, for scanned PDF pages.
#   macOS    brew install tesseract
#   Ubuntu   apt-get install tesseract-ocr
# Without it ingestion still succeeds, but pages with no text layer are
# skipped — 135 of the 3,255 pages in the current knowledge base need it.
#
# Models download on first use and cache under ~/.cache/huggingface:
#   BAAI/bge-small-en-v1.5   384-dim, 512-token window   ~130 MB
#   BAAI/bge-reranker-base   cross-encoder reranker      ~1.1 GB
#
# NOTE: rank-bm25 is no longer required. BM25 term weights are computed at
# ingest by edupilot/retrieval/sparse.py and stored as Pinecone sparse
# vectors, which removes the per-process in-memory index that was rebuilt on
# every upload.

-e .
